# python-security-tools
A collection of practical Python scripts developed for network discovery, packet sniffing, protocol manipulation (ARP/DNS), web security scanning, and OSINT reconnaissance.

🛠️ Included Tools
Network & Scanning (net_scan.py, scanner.py, vulnerability_scanner.py, script.py): Tools designed for network mapping, host discovery, and identifying potential vulnerabilities or open ports.

Spoofing & Man-in-the-Middle (ARP_spoof.py, detector_arp_spoof.py, dns_spoof.py): Implementation of ARP cache poisoning, spoof detection mechanisms, and DNS response redirection.

Traffic Analysis (packet_sniffer.py, ipfuscator.py): Packet inspection utilities for monitoring network traffic and obfuscating IP addresses.

Payload & Interception (replace_donwload.py): Utility scripts to intercept downloads or manipulate network data packets in transit.

Reconnaissance (blackbird.py): OSINT tool integrations for digital footprinting and information gathering.

⚠️ Disclaimer
Educational Use Only: These scripts are provided strictly for educational purposes, ethical hacking training, and authorized security testing. Do not use these tools against targets without explicit, written permission from the system owners. Unauthorized testing is illegal.
